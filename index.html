Connect Firebase

This app needs a free Firebase Realtime Database before it can run:

  1. Create a project at console.firebase.google.com
  2. Add a Realtime Database (Build → Realtime Database → Create database).
  3. Copy the web app config into js/config.js.

Full instructions are in the project's README.md.
